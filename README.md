# 🌌 Acerca del proyecto

**Bad Gateway Streaming Platform** fue desarrollado como parte de una asignación académica de **Interactive Development 100** durante el cuarto semestre.

El objetivo principal fue diseñar una plataforma de streaming de películas en equipo utilizando:

- 🌐 Desarrollo web moderno
- 🔄 Control de versiones con Git
- ☁️ Colaboración mediante GitHub
- 🎨 Diseño responsive
- 🧠 Trabajo colaborativo

El proyecto permitió a los integrantes practicar desarrollo frontend, organización de proyectos y trabajo en equipo en un entorno realista.
